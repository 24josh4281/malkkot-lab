# 김재원 말꽃연구소 인터뷰 아카이브

김재원 아나운서가 진행한 인터뷰 영상(책과삶, 김재원TV, CGN 하늘빛향기, C채널 광야예찬)을 게스트, 주제, 진행자의 말, 게스트의 반응으로 찾아보는 내부 학습용 대시보드입니다.

- 원자료는 유튜브 자동 자막이며 화자 구분, 반응 판정, 효과 점수는 AI 분석입니다. 인용은 시각 링크로 원본 영상을 확인하세요.
- 검색 엔진에 잡히지 않도록 noindex를 설정했습니다. 링크를 아는 사람은 누구나 볼 수 있습니다.
- 영상과 자막 원문은 이 저장소에 없습니다. 각 장면은 유튜브 원본으로 연결됩니다.
- `index.html`을 열면 동작하는 정적 사이트이며 서버가 필요 없습니다.
