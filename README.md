# 김재원 말꽃연구소 홈페이지

리더 스피치 컨설팅을 소개하는 한 페이지짜리 정적 홈페이지입니다. GitHub Pages로 공개합니다.

- `index.html`: 홈페이지. 글꼴(Google Fonts)을 뺀 CSS · JS · 이미지가 모두 들어 있습니다.
- `privacy.html`: 개인정보처리방침.

## 상담 신청

상담 신청 양식은 Google Apps Script 웹 앱으로 전송되어 관리용 Google 스프레드시트에 저장되고, 알림 메일로 전달됩니다. 접수 주소는 `index.html`의 `ENDPOINT` 값에 넣습니다. 값이 비어 있으면 양식 대신 전화 · 이메일 안내가 나옵니다.

## 권리

저서 표지 이미지의 권리는 각 출판사에, 프로필 사진의 권리는 촬영자에게 있습니다.
