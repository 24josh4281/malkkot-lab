# 김재원 말꽃연구소 홈페이지 시안

리더 스피치 컨설팅을 소개하는 한 페이지짜리 정적 홈페이지 시안입니다. `index.html` 하나에 글꼴(Google Fonts)을 뺀 모든 CSS · JS · 이미지가 들어 있습니다.

- 공개 전 시안이라 검색 엔진 색인을 막아 두었습니다(`<meta name="robots" content="noindex, nofollow">`). 정식 공개 때 이 줄을 지우십시오.
- 저서 표지 이미지의 권리는 각 출판사에, 프로필 사진의 권리는 촬영자에게 있습니다. 공개 운영 전에 사용 허락을 받으십시오.
- 연락처와 경력 중 일부(서강대학교 겸직교수, 〈책과삶〉 · 〈마당밖재원〉 진행, 장차관급 코칭 이력)는 당사자 확인이 필요합니다.
